Idle Standby vs. Active Discharge

💤 IDLE STANDBY

Monitors quiescent sleep drain when the device is locked, display is turned off, and CPU enters C-states.

Typical: ~110 mA ~0.42 W

🔋 ACTIVE DISCHARGE

Measures real in-use electrical draw during display-on sessions, gaming workloads, video streaming, and high compute tasks.

Typical: ~580 mA ~2.25 W
Engineering Highlights

Built for Performance & Accuracy

🔥

Real Physical Temperature

Bypasses simulated OS indicators to query the actual physical battery thermistor sensor with 0.1°C precision and color-coded risk indicators.

⚡

Wattage & Current Telemetry

Real-time computing of electrical wattage ($W = V \times A$) and instantaneous mA with automatic polarity normalization across Android chipsets.

🪟

Floating Screen Overlay HUD

Lightweight draggable floating pill on top of any game, benchmark, or navigation app displaying live Temp, Watts, and mA with tap-to-expand.

⏱️

4-Hour Sliding Min / Max

Hardware rolling statistical aggregations calculating exact minimums, maximums, and averages across 4-hour historical windows.

🔔

High-Temp Hold Alarm

Protective thermal alarm that triggers loud ringtones and vibrations only if temperature exceeds your threshold for a continuous hold duration.

🌿

Zero-Drain Eco Architecture

Screen-aware adaptive frequency (2s screen-on, 25s screen-off) and SQLite Write-Ahead Logging batching to guarantee 0.0% standby battery drain.

Quick Install via ADB

Connect your phone via USB with USB Debugging enabled, then execute:

adb install -r -d -g ThermalAmp.apk
adb shell appops set com.thermalamp.app SYSTEM_ALERT_WINDOW allow
adb shell am start -n com.thermalamp.app/.MainActivity
